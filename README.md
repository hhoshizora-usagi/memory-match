# 神経衰弱

**ver. 1.1.0**

ブラウザだけで遊べる記憶ゲーム。
「ほかのゲーム」枠の見た目・アニメーション改善シリーズ、2本目です。

## 方針

ルール（4×3 / 4×4 / 4×5 の3段階・手数・タイム・ベスト記録）は**従来どおり**。
見た目・アニメーション・画面サイズ対応だけを作り直しました。
難易度は変えていないので、前と同じ感覚で遊べます。

## 変えたところ

### 見た目

- **絵柄をSVGで描きおろした** — 絵文字から、うさぎ・ねこ・くま・さかな・ほし・はな・ケーキ・いちご・にじ・ちょうちょの10種に。
  カードサイズが変わっても輪郭が崩れません。
- **カードの裏を作り込んだ** — 青から紫へのグラデーションに、点線の枠と丸いしるし。
  表は白地にうっすら光る枠で、絵柄がいちばん映えるようになりました。
- **背景にふわっとした光の玉** — ゆっくり動き続けるので、考えている間も退屈しません。

### アニメーション

- **めくる動き** — カードが3Dでパタッと倒れるように回り、少し行き過ぎてから戻るイージング。
  ペラッという音も付きました。
- **揃った瞬間** — 2枚がふわっと浮いて金色に光り、星が飛び散って「ペア！」が浮かぶ。
  カードの右上に緑のチェックも付きます。
- **外したとき** — 2枚がちょっと揺れて色が抜け、「ちがう…」と出ます。
  めくった瞬間に「うん、外したな」と分かる気持ちよさを大切にしました。
- **コンボ** — 続けて揃えると「n COMBO!」が弾んで出ます。
- **クリア画面** — 手数がカウントアップし、ランクのバッジが弾み、紙ふぶきが舞います。

### その他

- **音** — Web Audio で合成した効果音（めくる／ペア／ちがう／クリア）。
  外部ファイルなしで鳴ります。右上のボタンでミュート可。
- **難易度切り替え** — 画面上部のボタンで かんたん／ふつう／むずかしい をいつでも変更できます。
- **ベスト記録は難易度ごと**に保存されます（localStorage）。
- **画面サイズ対応** — スマホの縦・横・PCに合わせて、カードが入りきる最大サイズになります。
- **動きを控えめに設定している端末** — OSで「動きを減らす」を選んでいると、アニメーションが止まります。

## 変えていない中身

- 難易度3段階（4×3＝6ペア／4×4＝8ペア／4×5＝10ペア）
- 2枚めくって同じなら揃う、違えば戻る
- 手数のカウントとタイマー
- ベスト記録（最少手数）の保存
